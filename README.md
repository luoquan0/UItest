# 鼓浪屿 GULANGYU · 海上花园 / 音乐之岛

电影感景区介绍网站。以海岛黄昏影像、鎏金标题、沉浸式滚动叙事、交互地图和横向影像长卷呈现鼓浪屿的建筑、园林与音乐文化。

## 在线预览

https://luoquan0.github.io/UItest/

## 页面内容

- 首页：全屏海岛影像、鎏金流光中文标题、分层英文标题、粒子与海面微光。
- 景区介绍：岛屿文化、历史国际社区、世界遗产信息。
- 三章节沉浸故事：海风入巷、百年建筑、琴岛回响。
- 必游景点：日光岩、菽庄花园、钢琴博物馆、历史建筑与海岸漫步。
- 互动地图：可点击景点热点，查看简要介绍。地图为艺术示意图，不用于导航。
- 游玩攻略：四段慢游路线示意。
- 横向影像长卷：滚动页面时横向浏览建筑、花园、钢琴与海湾画面。
- 影像画廊：图片灯箱、前后切换。
- 游客服务：轮渡交通、票务预约、开放时间、游览须知提示弹窗。

## 动效与交互

- 首屏鎏金渐变文字与周期性流光扫过。
- 鼠标视差：背景、标题、光晕和装饰轨道产生不同位移。
- Canvas 粒子与低强度海面波光线条。
- 滚动驱动三章节背景和文案切换。
- 横向滚动影像长卷（桌面端）；移动端改为自然网格布局。
- 景点卡片轻量 3D 倾斜与指针高光。
- 交互地图热点、路线节点、图片灯箱、站内搜索、服务信息弹窗。
- 用户主动开启的合成钢琴音色与柔和海浪噪声；默认静音，无自动播放。
- 支持 prefers-reduced-motion，减少动态效果时关闭持续动画与粒子。

## 本地运行

无需安装依赖。直接打开 `index.html`，或在项目目录执行：

```bash
python -m http.server 8000
```

访问 http://localhost:8000 。

## 内容与安全说明

这是景区介绍网站的概念设计预览，不是鼓浪屿官方运营网站。地图为视觉示意，不提供真实地理定位或导航；路线仅为游玩灵感。门票、轮渡班次、开放时间等动态信息请以官方实时公告为准。
