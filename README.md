# 清朗政务 · 政务智能助手

面向政府机关、事业单位内部办公场景的 AI 对话平台前端交互原型。

## 当前版本

本仓库当前交付为无需构建工具的静态交互原型，以 `index.html` 为入口。采用原生 HTML/CSS/JavaScript，不依赖 CDN、远程字体或外部运行时资源，适合在内网环境预览。

### 已实现页面
- AI 对话：会话新建与切换、历史搜索、快捷问题、模型选择、附件选择展示、模拟回复。
- 知识库：文档列表、搜索筛选、知识库筛选、文件选择展示、新建知识库、删除记录。
- 模型中心：模型列表、新增、编辑、启停、设置默认模型。
- 应用管理：应用列表、新增与配置。
- 用户管理：用户列表、新增、编辑、启停。
- API 管理：演示密钥列表、新增与启停。
- 运行监控：演示指标、趋势图与服务状态。
- 系统设置、审计日志。
- 浅色/深色主题、侧边栏折叠。
- 浏览器 localStorage 持久化演示数据。

## 本地运行

无需安装依赖。直接用浏览器打开 `index.html` 即可。

也可以在项目根目录运行：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000 。

## 重要说明

当前是前端交互原型，不是真实政务生产系统：
- AI 回复为模拟内容，尚未连接 Ollama、llama.cpp、vLLM 或云端模型。
- 文件选择仅在浏览器展示文件名和大小，不会上传、解析或入库。
- 用户、角色、API Key 和权限均为演示数据；前端菜单显示不构成服务端安全控制。
- 数据仅保存在当前浏览器的 localStorage。
- 不要输入国家秘密、工作秘密、个人敏感信息或真实 API 凭证。

正式部署前必须建设服务端身份认证、RBAC 权限校验、审计、数据隔离、密钥管理、文件安全检查与内网模型服务接口。
