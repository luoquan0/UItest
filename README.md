# 鼓浪屿 GULANGYU · 海上花园 / 音乐之岛

沉浸式景区介绍网站，采用电影感海岛影像、编辑式排版、分章节滚动叙事与轻量 3D 交互动效。

## 在线预览

https://luoquan0.github.io/UItest/

## 页面结构

- 首页：全屏海岛黄昏影像、品牌标题、探索入口、滚动提示。
- 景区介绍：岛屿文化、历史国际社区、世界遗产信息。
- 沉浸式故事：海风入巷、百年建筑、琴岛回响三个章节；滚动时固定画面并渐变切换。
- 必游景点：日光岩、菽庄花园、钢琴博物馆、历史建筑与海岸漫步。
- 游玩攻略：交互式四段慢游路线示意。
- 影像画廊：图片灯箱、前后切换。
- 游客服务：轮渡交通、票务预约、开放时间、游览须知提示弹窗。

## 动效与交互

- 电影感开场：品牌预加载、标题分层显现、按钮柔和呼吸光效。
- 首屏 3D 视差：鼠标移动带动背景、标题、光晕与装饰轨道产生不同幅度位移。
- 氛围粒子：少量低负载 Canvas 光尘，随页面可见状态暂停/恢复。
- 沉浸式滚动叙事：滚动经过三章时切换场景照片、章节文案和进度编号。
- 故事场景支持鼠标视差，图片层与光影层有轻微空间偏移。
- 景点与画廊卡片支持轻量 3D 倾斜、图片放大和跟随指针的柔和高光。
- 顶部导航随滚动切换状态，页面滚动进度条与滚动入场动画。
- 景点横向滑动、路线节点切换、图片灯箱、站内搜索与游客服务弹窗。
- 移动端保留主要内容与导航交互。
- 支持 prefers-reduced-motion，减少动态效果时关闭持续动画和粒子。

## 本地运行

无需安装依赖。直接打开 `index.html`，或在项目目录执行：

```bash
python -m http.server 8000
```

访问 http://localhost:8000 。

## 内容说明

这是景区介绍网站的概念设计预览，不是鼓浪屿官方运营网站。页面中关于开放时间、门票、轮渡班次等动态信息不做猜测，提示游客以官方渠道实时公告为准。路线为设计示意，不代表官方推荐线路或精确导航。
